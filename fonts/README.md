# Fonts

Bundled because a browser has none of the computer's fonts to fall back on. All under the SIL Open Font License.

- `Jost.ttf` (the desk's writing) and `LibreBaskerville.ttf` (headings, song titles): copied from Atlas, with their OFL texts.
- `NotoSansSymbols2-Regular.woff2` and `NotoSansMath-Regular.woff2`: the symbols on the desk's buttons (▶ ◀ ✕ ☰ ⟳ 🔊),
  as fallbacks. From Blender 4.3's `datafiles/fonts` (Google's Noto fonts, OFL).
